# 直接记账 · 安装包

Android 本地记账应用的公开安装包仓库。此仓库仅提供版本说明、主应用 APK 和更新元数据，不包含源码、个人账本或签名密钥。

在本仓库的 Releases 页面下载主应用 APK。已有安装请先备份，再覆盖安装；不要卸载旧版。0.8.0 起可在“设置 → 软件更新”检查、下载并交由系统确认安装。

最低支持 Android 8.0。交易采集需要用户授权，并受应用通知内容、页面可读性和手机后台策略影响，不保证所有渠道和交易场景都能自动识别。信息不充分时需要核对。鸿蒙兼容工具不保证能读取原生系统应用通知。

账本默认保存在手机本地；软件更新仅下载公开版本文件，不上传账本。备份文件包含财务数据，请勿上传到公开仓库。

源码由维护者在独立私有仓库管理。公开下载 APK 不代表提供源码再分发许可。
